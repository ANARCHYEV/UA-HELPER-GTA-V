# Прозорість UA Helper

Публічний код дозволяє перевірити програму. Сам факт публікації коду або контрольної суми не гарантує безпеку виконуваного файлу.

## Мережа і дані

| Механізм | Що передається | Код |
| --- | --- | --- |
| OpenRouter | Запит, знайдені пункти правил і особистий API ключ | app/src/main/services/ai-client.ts |
| API спільноти | Запити синхронізації, код входу, ідентифікатори профілю; голосовий запис при використанні розпізнавання | app/src/main/services/server-client.ts |
| GitHub Releases | Перевірка версії та завантаження оновлення | app/src/main/services/updater.ts |
| Discord Desktop | Локальна Rich Presence через IPC | app/src/main/services/discord-presence.ts |

Ключ OpenRouter шифрується через Electron safeStorage. Він передається OpenRouter для виконання запиту, але не API спільноти. Історія відповідей, налаштування, профіль та кеш правил зберігаються локально в SQLite. Мікрофон використовується за дією користувача. Автозапуск налаштовується користувачем.

## Перевірка релізу

Windows файли збираються GitHub Actions з тегу вихідного коду. У вкладці Actions можна переглянути команди збірки. Реліз містить SHA256SUMS.txt; локальна перевірка: `Get-FileHash '.\UA-Helper-1.0.0-portable-ui.exe' -Algorithm SHA256`.

Оновлення не завантажуються автоматично й не встановлюються при закритті програми. Встановлення запускається кнопкою після завершення завантаження. Portable версію слід замінювати вручну з GitHub Releases; автоматична установка призначена для NSIS версії.

## Публікація

1. Створити публічний репозиторій і додати лише вихідні файли, lockfile та документацію. Не додавати .env, ключі, бази, логи та профілі.
2. Оновити версію в app/package.json, кореневому package.json, app/config/app.config.json та package-lock.json.
3. Відправити тег `v<версія>`. Workflow автоматично підставляє власника і репозиторій у конфіг оновлень.
4. Перевірити файли draft релізу, журнал Actions і контрольні суми, потім опублікувати реліз. До публікації клієнти його не отримують.

Токен GITHUB_TOKEN надається лише workflow, не потрапляє в застосунок. Підпис Windows видавця поки не налаштований. Для незалежного огляду варто передати посилання на тег, workflow та реліз, а не лише exe.
