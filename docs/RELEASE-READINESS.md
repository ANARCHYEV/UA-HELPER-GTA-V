# Стан підготовки релізу

Перевірено 15 листопада 2026 року. Це стан перевірки, а не гарантія готовності.

## Підтверджено

- Публічний API відповідає health: ok через HTTPS.
- Вихідний код, конфіг та Windows release workflow опубліковані в GitHub.
- Оновлення налаштовані на ANARCHYEV/UA-HELPER-GTA-V; автоматичне завантаження та встановлення при виході вимкнені.
- Renderer має contextIsolation=true і nodeIntegration=false; відкриття сторонніх вікон обмежене.

## Блокери

- API повертає 0 правил і 0 законів. Відповіді ШІ на офіційних правилах не можна перевірити до наповнення бази.
- API повідомляє telegramAuth=false. Потрібні актуальний токен бота, секрет webhook і перевірка входу з реальним Telegram профілем.
- Discord авторизація і перевірка підписки не налаштовані. Перевірка підписки у клієнті вимкнена.
- Публічного GitHub Release ще немає. Потрібно виконати workflow, перевірити артефакти та оновлення між двома версіями NSIS. Portable замінюється вручну.
- Відповіді OpenRouter потребують особистого ключа. Реальний запит, streaming, скасування й джерела потребують наскрізної перевірки з ключем користувача.
- Голосова транскрипція потребує окремої перевірки доступності сервісу й мікрофона.
- Підпис Windows видавця не налаштований. SHA256 не є підписом видавця.
- sandbox=false у webPreferences потребує окремої перевірки сумісності preload з sandbox перед увімкненням.

## Останні зміни коду

- Telegram webhook відхиляється без налаштованого секрету.
- Код входу приймається тільки від власника особистого Telegram чату; вже підтверджений код повторно не прив'язується.

Ці зміни backend мають бути розгорнуті на VPS, перш ніж вважати їх діючими у production.
